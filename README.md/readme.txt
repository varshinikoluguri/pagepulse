# Page Pulse - Website SEO Analyzer

## Overview
Page Pulse is a web application that analyzes a website and provides basic SEO metrics.

## Features
- Website Status Code
- Response Time
- Page Title
- Meta Description
- H1 Count
- Images without Alt Text
- Word Count

## Technologies Used
- Python
- FastAPI
- Requests
- BeautifulSoup
- HTML
- CSS
- JavaScript

## How to Run

### Backend
bash
cd backend
python -m uvicorn app:app --reload


### Frontend
bash
cd frontend
python -m http.server 5500


Open:


http://localhost:5500
